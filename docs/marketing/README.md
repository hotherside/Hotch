# Marketing assets

Everything for the README, the website and social posts, in one place. All of it shows the real app on demo data; session names and figures are fictional. Sources and render steps are in [Showcase/README.md](../../Showcase/README.md).

## Video

Filmed from the real app's own windows with `Hotch --render-tour` (see [Showcase/README.md](../../Showcase/README.md)): no screen recording, and the windows are never on screen.

## Stills and social (2.4 design)

These were cropped from the 2.4 reel's footage and still show its six-section rail and card. Re-render them with the HyperFrames pipeline before using them again.

| File | What it shows |
|---|---|
| `stills/hotch-hero.jpg` | Headline beside the open AI card |
| `stills/hotch-split.jpg` | Light and dark, split across one live card |
| `stills/hotch-notch.jpg` | The original notch view |
| `stills/hotch-alert.jpg` | An alert growing out of the tab, light appearance |
| `social/hotch-social-preview.png` | GitHub social preview, 1280 x 640 (Settings > Social preview) |

In the 2.4 stills the desktop around Hotch is drawn: generated wallpapers, a stand-in menu bar, terminal and Dock, and no Apple hardware, with titles set in Inter (SIL Open Font License). The current media use a plain backdrop and no type.
